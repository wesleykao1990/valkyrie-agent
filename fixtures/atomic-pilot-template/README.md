# Valkyrie Atomic pilot fixture

This is a disposable, dependency-free repository template for the Milestone 5
pilot. It is intentionally not a product repository.

The fixed task is to implement `normalizeProjectSlug` in
`src/normalize-project-slug.js` without changing any other source or test file.
The control plane creates a separate Git repository from this template before a
pilot run; Hermes never supplies its path or command.
