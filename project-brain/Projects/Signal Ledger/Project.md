# Signal Ledger

Signal Ledger collects posts, filings, and public investment signals from selected creators and public figures. The main challenge is reliable, deduplicated ingestion across heterogeneous platforms.

## Current constraints

- Preserve original source links and publication timestamps.
- Distinguish collection failure from a true absence of new signals.
- Keep credentials and platform-specific adapters isolated.
