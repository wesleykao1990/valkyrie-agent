# Ovalo

Ovalo is an AI-native personalized language-learning product. The current milestone focuses on live conversation, pronunciation feedback, CEFR speaking evaluation, and low-latency language workflows.

## Current constraints

- Mobile and voice interactions must remain responsive.
- Learner data and project decisions must remain portable across model vendors.
- Generated curriculum and feedback require explicit evaluation and evidence.
