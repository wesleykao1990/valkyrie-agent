# Atomic Pilot

The Milestone 5 fixture is disposable and non-production. Its purpose is to prove
the governed Hermes → control plane → Atomic → isolated writer → deterministic
evidence → approval → memory-proposal lifecycle. It must never receive a product
repository, production credential, unrestricted network egress, real PR action,
merge, deployment, or automatic canonical-memory promotion.
