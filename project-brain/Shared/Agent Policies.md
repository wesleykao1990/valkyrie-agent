# Agent policies

- One task has one root orchestrator.
- Agents may capture episodic learnings but may not silently promote canonical decisions.
- Production deployment, protected-branch merge, destructive data changes, and secret expansion require human approval.
- Current Linear and Git state outrank remembered status.
- Every writing candidate receives an isolated workspace and a single-writer lease.
